# App assets

Partner logos are unchanged copies from `public/assets/`.

`FerryBoard/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png` is the native app icon. It was created using the built-in imagegen tool with `public/assets/app-icon-512.png` as its edit reference, then sized for the asset catalog. The web icon is unchanged.

Final generation prompt:

> Create a 1024 by 1024 pixel faithful high resolution version of this existing app icon. Preserve exactly the existing Hello Kitty white face, thick black outline and whiskers, yellow oval nose, two black eyes, red bow on upper right, all proportions and layout, centered white background. This is a production icon asset size upgrade only. Do not redesign or add any elements, text, border, shadows or rounded corners. Pure opaque white background reaching every edge. Square output PNG, 1024x1024.
